# Diabetic Retinopathy AI Screening

An AI-powered platform for diabetic retinopathy
detection, patient history management, explainable
predictions, RAG-based assistance and automated
screening report generation.

## Technology Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Python, FastAPI
- AI/ML: PyTorch, OpenCV
- Database: PostgreSQL, pgvector
- ORM: SQLAlchemy
- Reports: ReportLab

## Project Status

Phase 1 - Environment Setup

## Disclaimer

This project is an academic research prototype
and is not a clinically validated diagnostic system.
